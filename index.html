Level 1 - HTML Basics

  1. What is HTML?
    • HTML stands for HyperText Markup Language.
    • Used to create web pages.
  2. HTML Attributes
    • Provide additional information about elements.
    • Written inside opening tags.
  3. Common Attributes
    • href - Used with anchor tags.
    • src - Used with images.
    • alt - Alternative text for images.
    • title - Tooltip text.
    • id - Unique identifier.
    • class - Groups elements for styling.

Level 3 - Forms

  1. What is a Form?
    • Forms are used to collect user input.
    • The <form> tag acts as a container for form elements.
  2. Text Input
    • Used to enter text.
  3. Password Input
    • Hides user input.
  4. Email Input
    • Accepts email addresses.
  5. Number Input
    • Accepts numeric values.
  6. Date Input
    • Select a date.
  7. Radio Buttons
    • Allows selecting one option from a group.
      • Male Female
  8. Checkbox
    • Allows selecting multiple options.
      • HTML CSS JavaScript
  9. File Input
    • Used to upload files.
  10. Color Picker
    • Select a color.
  11. Range Slider
    • Select a value from a range.
  12. Textarea
    • Used for multi-line text input.
  13. Dropdown Menu
    • Created using select and option tags.
  14. Label Tag
    • Associates text with a form control.
  15. Submit Button
    • Submits form data.
  16. Reset Button

Level 4 - Tables

  1. What is a Table?
    • Tables are used to display data in rows and columns.
    • The <table> tag is the container for a table.
  2. Table Tag
    • Creates a table.
    • Syntax: <table></table>
  3. Table Row - tr
    • Defines a row inside a table.
  4. Table Heading - th
    • Defines a header cell.
    • Text appears bold and centered by default.
  5. Table Data - td
    • Defines a normal data cell.
  6. Simple Table Example

    • Merges multiple rows into a single cell.

  8. Colspan Attribute
    • Merges multiple columns into a single cell.

  9. Table Sections
    • <thead> - Groups header content.
    • <tbody> - Groups main table data.
    • <tfoot> - Groups footer content.
